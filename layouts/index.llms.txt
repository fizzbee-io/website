# FizzBee

> The easiest formal specification language and model checker for the full development cycle: requirements analysis, design verification, and model-based testing.

FizzBee specs look like Python: you model a system as actions on state, then the model checker explores every interleaving to verify safety and liveness properties, and the model-based testing runner checks a real implementation against the model. Each page below is available as clean markdown at the listed URL; the HTML version is the same URL without `index.md`.
